## Overview

Ningsih is an autonomous agentic AI assistant that manages scheduling and workflows proactively. It integrates Google Calendar and Tasks with Telegram, backed by persistent long-term memory, so requests made in a chat become scheduled actions that happen on their own.

## Problem

Personal assistants live in the chat, but scheduling lives in calendars and task lists. Bridging them manually — copying a meeting time from a message into a calendar — is exactly the kind of repetition that should automate itself.

## Solution

An agentic loop with tool calling at its core:

- **Tool-calling architecture**: the model plans, then calls Google Calendar / Tasks APIs as tools.
- **Persistent context**: structured outputs (JSON schema matching) keep state consistent across turns.
- **Long-term memory**: conversation and task history persist so the assistant remembers context between sessions.
- **Background scheduling**: scheduled jobs execute proactive actions (reminders, follow-ups) without a prompt.

## Engineering Decisions

- **Structured outputs (JSON schema)** over free-form model replies, for reliable tool dispatch
- **Supabase** for auth + Postgres in one managed service (free tier)
- **Modular API design** for multi-tenant concurrency
