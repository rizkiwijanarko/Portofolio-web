## Overview

**Ningsih** is a proactive mobile product that acts as an intelligent digital chief of staff. Instead of forcing people into rigid project-management boards, it helps manage calendars, habits, goals, small tasks, and personal context through natural conversation and voice.

It evolved from an earlier Telegram-bot prototype into a focused mobile experience backed by a real-time serverless platform and an agent engine that can take action on a person's behalf.

<PublicImage src="/previews/ningsih-app.jpg" alt="Ningsih mobile app showcase" />

## Problem

Busy professionals and people with ADHD often face executive dysfunction, time blindness, and calendar overload. Traditional productivity apps demand manual entry and constant context switching — exactly the friction that makes it hard to start. Ningsih is designed to turn an overwhelming thought into one approachable next step.

## Solution

Ningsih turns messy voice notes and brain-dumps into structured daily momentum:

- **Proactive morning kickoff** — prepares a daily briefing based on the person's schedule, goals, and energy pattern.
- **Natural voice and text input** — understands requests such as fitting a workout around a client proposal and an existing calendar.
- **Calendar-aware planning** — checks open time, detects conflicts, and connects actions to longer-term goals.
- **Small next steps** — breaks intimidating work into short, progressive actions so the person can begin without planning the entire task.
- **Low-pressure recovery** — offers distraction recovery, re-entry timers, and rest-day tolerance instead of treating one missed day as failure.

### Key Layers

1. **Mobile experience** — an Expo and React Native app with a dark, calm visual system, real-time data binding, voice capture, haptics, and local reminders.
2. **Application backend** — a serverless real-time backend stores users, goals, tasks, activities, calendar events, memories, and routines while enforcing tenant boundaries.
3. **Agent services** — language models interpret requests, choose appropriate actions, and return structured results that the app can display and update in real time.
4. **External services** — calendar synchronization, speech-to-text, authentication, and subscriptions connect through server-controlled integrations.

## Tech Stack

- **Frontend**: Expo, React Native, Expo Router, NativeWind
- **Backend**: Convex serverless real-time database and functions
- **AI**: DeepSeek V4 Flash via OpenRouter, with speech-to-text input
- **Auth and monetization**: Clerk and RevenueCat
- **Testing**: unit, backend, and device-level workflow testing

## Key Features

- Conversational AI agent with structured actions
- Goal alignment and milestone planning
- Habit and activity consistency tracking with rest-day buffers
- Focus sessions, distraction recovery, and a native task list
- Voice notes converted into actionable plans
- Two-way Google Calendar sync with conflict detection
- Weekly insights and progress visualizations
- Server-controlled free and paid entitlements

## Engineering Decisions

- **Real-time backend** so calendar updates, task changes, and agent actions stay synchronized across the app.
- **One action-oriented agent flow** so natural-language requests can produce useful changes instead of only generating advice.
- **Server-controlled permissions and entitlements** so account access and subscription state cannot be trusted only to the client.
- **Small-step planning** so the product supports starting and recovering, not only long-term planning.
