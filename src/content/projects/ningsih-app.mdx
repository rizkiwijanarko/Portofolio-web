## Overview

**Ningsih** is a proactive, multi-tenant mobile SaaS that acts as an intelligent digital chief of staff. Instead of forcing users into rigid project-management boards, it manages Google Calendar, tracks habits and goals, generates 3-tier micro-task decompositions, records long-term memories, and orchestrates day-part routines — all through natural conversation and voice.

It evolved from an earlier Telegram-bot prototype into a carefully designed mobile product: an Expo/React Native app backed by a serverless Convex real-time backend and a deep agent engine.

![Ningsih App Showcase](/Portofolio-web/previews/ningsih-app.jpg)

## Problem

Busy professionals and ADHD minds face **executive dysfunction, time blindness, and calendar overload**. Traditional productivity apps demand manual entry, rigid boards, and constant context-switching — exactly the friction that stops people from starting. What's missing is a system that *proactively* structures the day and breaks overwhelming work into approachable steps.

## Solution

Ningsih turns messy voice notes and brain-dumps into structured daily momentum:

- **Proactive morning kickoff** — prepares a daily briefing based on your chronotype (Early Bird vs. Night Owl) and energy level before you ask.
- **Speak or text naturally** — raw voice notes ("I'm overwhelmed with this client proposal and need to fit in a gym session") are transcribed and parsed into actions.
- **Smart organizing & calendar sync** — cross-references requests against Google Calendar for open slots and conflict detection, linking actions to overarching goals.
- **2-minute micro-steps** — decomposes intimidating tasks into three difficulty tiers (Easy ~2m / Medium ~3m / Larger ~5m) with "Just do step 1" framing to break initiation inertia.
- **Zero-guilt momentum** — distraction-recovery prompts, 5-minute re-entry timers, and rest-day tolerance buffers so a single off-day never wipes progress.

### Key Layers

1. **Client Layer (Mobile App)** — Expo SDK 57 (React Native 0.86) with Expo Router, NativeWind (Tailwind CSS) + a custom **Ember Studio** design system (dark-mode-first ember gradients, glassmorphism, Playfair Display + Source Sans 3). Real-time data binding via the Convex React Native client (`useQuery`/`useMutation`/`useAction`); voice recording via `expo-audio`, haptics via `expo-haptics`, smart local alerts via `expo-notifications`.

2. **Backend Layer (Convex Serverless)** — a document store with relational multi-tenant models (users, goals, milestones, tasks, activities, calendar events, memories, day-part routines). A deep agent engine (`convex/agent/`) provides a unified 10-tool execution registry with structured tool parsing, Socratic goal alignment, and fallback resilience. The calendar-sync engine runs 15-minute background cron syncs with immediate on-write projection, conflict detection, and RRULE expansion. Entitlements are server-authoritative (Free vs. Plus/Premium).

3. **External Services** — OpenRouter powering DeepSeek V4 Flash for low-latency reasoning and tool dispatch (OpenAI API as fallback); OpenAI Whisper for voice-to-text; Clerk Expo for Google OAuth; RevenueCat for Google Play / App Store subscriptions with server webhook validation.

## Tech Stack

## The Agent Tool Registry

The agent's deep module registry (`convex/agent/toolRegistry.ts`) co-locates 10 schemas and handlers:

| Tool | Purpose |
|---|---|
| `logActivity` | Log habits, workouts, skips, or misses with pillar categorization and streak updates |
| `fetchTodaySchedule` | Unified schedule of Ningsih events, Google Calendar events, and completed activities |
| `scheduleEvent` | Schedule events with conflict checking, goal linking, and RRULE recurrence |
| `alignGoal` | Interactive Socratic alignment session for ambiguous goals |
| `manageGoal` | Create, update, pause, or complete long/short-term goals |
| `manageTask` | Create, list, or complete tasks in the native Focus List |
| `suggestMicroTask` | Decompose overwhelming tasks into 3 tiered micro-steps (2m / 3m / 5m) |
| `rememberContext` | Store constraints, preferences, and details into long-term memory |
| `reportScreenTime` | Log distraction time and generate somatic reset + re-entry micro-actions |
| `generateWeeklyReview` | Synthesize weekly metrics, focus hours, and key wins into an insights review |

## Key Features

- **Core AI agent loop & tool calling** — DeepSeek V4 Flash with real-time tool execution and structured outputs
- **Socratic goal alignment** — 3-tier milestone cascade (Short/Long-term Goals → Sub-milestones → Sprint Tasks) with quick-select chips
- **Habit & activity consistency engine** — 30-day rolling consistency score, per-activity streaks, rest-day buffers, comeback celebrations
- **Focus sessions & native Focus List** — focus timer, ambient sound, distraction recovery, `/tasks` management
- **Voice note input** — native capture + Whisper transcription into structured tool calls
- **Google Calendar 2-way sync** — agenda, conflict detection, recurring events (RRULE) with tiered capabilities
- **Weekly insights & native charts** — Gifted Charts: focus hours, habit consistency %, AI-synthesized weekly reviews
- **Freemium entitlements** — server-authoritative Free vs. Plus tiers with RevenueCat and in-app paywalls

## Engineering Decisions

- **Convex serverless** for real-time reactivity (queries/mutations/actions) without managing a backend fleet — the document store handles relational multi-tenant models.
- **Deep tool registry pattern** — a single unified registry with co-located schemas keeps 10 tools consistent, parseable, and fallback-resilient.
- **Server-authoritative entitlements** — webhook verification and tier gating on the server, not the client, so paywall state can't be spoofed.
- **15-minute calendar cron + on-write projection** — predictable background sync with immediate local consistency.
