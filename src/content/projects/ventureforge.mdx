## Overview

VentureForge is a multi-agent workflow that takes a startup idea and scores it against real-time signals from Hacker News, Product Hunt, and YouTube. It evaluates market relevance and product-market fit with structured LLM pipelines instead of vibes.

## Problem

Validating a startup idea means scanning multiple real-time sources and synthesizing whether the market actually cares. Doing that by hand is slow, inconsistent, and biased by whatever you happened to read last.

## Solution

A LangGraph multi-agent graph where each agent owns a source:

- **Source agents** ingest real-time data from Hacker News, Product Hunt, and YouTube APIs.
- **Evaluation pipelines** assess market relevance and product-market fit against the ingested data.
- **Scoring** produces a structured verdict per idea.

The inference layer runs a self-hosted open-source LLM — Qwen3-35B served with vLLM on AMD MI300X GPUs — for low-latency, cost-controlled evaluation.

## Architecture

The workflow routes an idea through dedicated source collectors, a shared evaluation stage, and a final scoring step. Each stage contributes structured evidence so the result can be traced back to the signals that influenced it.

## Tech Stack

- **Orchestration**: LangGraph (multi-agent graph)
- **Inference**: vLLM serving Qwen3-35B on AMD MI300X
- **Interface**: Gradio
- **Integrations**: Hacker News, Product Hunt, YouTube APIs

## Key Features

- Multi-agent source ingestion
- Structured startup scoring
- Self-hosted open-source LLM inference
- Interactive Gradio client

## Engineering Decisions

- **LangGraph** over a hand-rolled loop — the graph shape maps naturally to agent pipelines
- **Self-hosted Qwen3-35B on vLLM/AMD** — open weights, no per-token API cost, low-latency GPU inference
- **Gradio** for a quick interactive surface over the graph

## Challenges

The main challenge is keeping the evaluation grounded in current evidence without letting one noisy source dominate the result. Separating collection, analysis, and scoring makes each stage easier to inspect and calibrate.

## Results

The working prototype combines multiple live sources, produces a structured score, and exposes the workflow through an interactive Gradio interface. Calibration against known outcomes remains part of the next iteration.

## Lessons Learned

Multi-agent workflows are most useful when each stage has a narrow responsibility and produces an inspectable intermediate result.
