# Personal Portfolio Website Blueprint

## Objective

Build a portfolio website that positions me as an AI Engineer building production-ready AI systems and AI-native SaaS products. The website should showcase engineering capability through products, architecture, technical decisions, and measurable impact.

The website should be content-driven rather than animation-driven.

---

# Source of Truth

Use the following assets as the only factual sources:

- Master Resume
- Personal Photograph
- Resume PDF
- Architecture diagrams
- Product screenshots
- Company logos (experience section)
- Project logos (if available)

If information is unavailable, leave a TODO placeholder instead of generating content.

# Content Philosophy

Present engineering capability through evidence.

Every major section should answer one of the following.

- What was built?
- Why was it built?
- How does it work?
- What engineering decisions were made?
- What measurable impact was achieved?
- What was learned?
- What is being built next?
